Recommender System (Learning Project)
Overview

This project is a learning implementation of a collaborative filtering recommender system built using Python and the LightFM library.
The goal of the project is to understand the fundamentals of recommendation systems, including user–item interactions, sparse matrices, and ranking-based models.

The system uses Last.fm user–artist play count data to generate top-N artist recommendations for users.
Key Concepts Covered
Collaborative Filtering
User–Item Interaction Matrices
Sparse Matrix Representation (COO format)
Ranking-based Recommendation (WARP loss)
Practical ML environment setup with Conda
Tech Stack
Python 3.10
NumPy
SciPy
LightFM
Conda (environment management)
